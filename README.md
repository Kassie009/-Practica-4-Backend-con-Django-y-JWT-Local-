# Proyecto Final: Django + React con Autenticación JWT, API Externa y SOAP

Este proyecto es la integración de un Backend en Django con un Frontend en React, desarrollado para el Resultado de Aprendizaje de las Unidades 2 y 3.

## 🚀 Características
- **Backend (Django):** API REST con autenticación JWT (SimpleJWT), CORS configurado y endpoints protegidos.
- **Frontend (React):** Enrutamiento con React Router v6, Context API para el manejo de sesión, Login y Dashboard protegido.
- **API de Terceros:** Consumo de la API de consejos (Advice Slip API) en el Dashboard.
- **Web Service SOAP:** Endpoint en Django que consume un servicio externo SOAP (calculadora) usando la librería `zeep`.

## 🛠️ Requisitos Previos
- Python 3.10+
- Node.js 18+
- Git
